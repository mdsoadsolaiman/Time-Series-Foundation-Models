# Data

The repository contains two completed research domains and two planned extensions.

| Domain | Dataset | Status | Local path / policy |
|---|---|---|---|
| Finance | Bitcoin BTC/USD minute OHLCV | Completed | `bitcoin/btcusd_1-min_data.csv`; local only, Git-ignored |
| Energy | Australian Electricity Demand, South Australia (T4) | Completed | `electricity/australian_electricity_demand_dataset.tsf` |
| Weather | To be selected under a frozen protocol | Planned | No dataset claimed |
| Transport | To be selected under a frozen protocol | Planned | No dataset claimed |

Exchange Rate is not part of the verified roadmap. Dataset-specific provenance, preparation, and reproduction notes are maintained in each domain directory.

Raw data are never treated as forecast evidence. Authoritative forecast vectors and derived evaluation tables are under `results/` and are protected by the hash ledger in `docs/authoritative_artifact_hashes.md`.
